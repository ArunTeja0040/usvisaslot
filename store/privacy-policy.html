SlotHunter — Privacy Policy

Last updated: 22 September 2026

SlotHunter is a private, invitation-only Chrome extension used by a single visa-appointment booking business and its own staff. It is not offered to the general public.

This policy explains what the extension stores, where it sends it, and what it deliberately does not do.

What the extension handles

To book an appointment on the user's behalf, the extension handles data belonging to the operator's clients:

  • Client login credentials for the US visa scheduling website (username and password)
  • Security question answers required by that website
  • Appointment preferences — wanted date range, consulate locations, number of applicants, visa category
  • Booking activity — which slots were seen, attempted and confirmed
Credentials are encrypted before they leave the device. Passwords and security answers are encrypted with AES-GCM using a key derived from a master password that only the operator knows. That master password is never transmitted and is not recoverable by anyone else.

What the extension does not do

  • No analytics, telemetry, tracking pixels or advertising
  • No data sold, rented or shared with any third party
  • No browsing history collected — it acts only on the visa scheduling site and its login page
  • No remote code execution; all code ships inside the extension package
  • No data used for anything other than booking appointments for the operator's own clients

Who can see what

The operator sees all client records. Staff accounts are scoped: a staff member sees only the clients assigned to them, and pricing information is withheld from staff entirely.

Retention and deletion

Client records persist until the operator deletes them. Deleting a client in the dashboard removes it from the shared database and from every connected device on the next sync. Uninstalling the extension clears everything held locally on that machine.

Google user data

The extension requests the spreadsheets scope solely to write the operator's client list into a spreadsheet that the operator chooses. It reads no other spreadsheet, and Google user data is never transferred to anyone. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
